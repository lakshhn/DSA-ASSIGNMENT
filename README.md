## Running the Code

All `.py` scripts can be run directly using Python 3:
```bash
python3 Algorithm_Analysis_Lab_Works/lab1.py
python3 Algorithm_Analysis_Lab_Works/lab2.py
python3 Assignments_Ext/Part_A_Recursion/part_a_q2.py
```

All `.ipynb` notebooks can be viewed interactively in Jupyter Notebook, VS Code, or directly on GitHub.
